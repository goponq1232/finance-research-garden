# Build a Loan Affordability Budget

**Approval is not the same as affordability.**

Start with monthly take-home income, then subtract realistic costs.

| Category | Example |
|---|---:|
| Take-home income | $4,800 |
| Housing | $1,450 |
| Food | $600 |
| Transportation | $450 |
| Utilities | $300 |
| Insurance | $250 |
| Existing debt | $500 |
| Savings | $400 |
| Other spending | $400 |
| Remaining | $450 |

A new $425 payment technically fits, but leaves only $25 of flexibility.

That is why a better affordability test asks:

> Can I make this payment consistently while still saving and handling normal surprises?

## Stress test

Try the budget again with:

- a $300 unexpected expense,
- a 10% temporary income drop,
- a higher utility bill.

If the budget immediately becomes negative, consider a smaller loan or another structure.
